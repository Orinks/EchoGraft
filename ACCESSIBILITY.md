# EchoGraft Accessibility

EchoGraft must be playable with no vision.

## Requirements
- Keyboard-first controls with gamepad-friendly command names.
- Semantic HTML menus, buttons, status panels, inventory, settings, and logs.
- Live screen-reader status for chamber, objective, selected seed, tuning parameter, tuning value, and solved state.
- Scrolling text event log for all meaningful audio cues.
- Independent sliders for master, ambience, UI, seed voices, hazards, and scan pulses.
- Reduced-motion and minimal-visual modes.
- No mandatory reflex timing in the main campaign.
- Critical information is available through sound and text.
- Visuals do not rely on color alone.

## Verification
Automated checks cover semantic boot flow and keyboard interactions. Manual screen reader verification remains required before claiming formal conformance.
